A SpaceXSI-enabled fork of CodeAlta Desktop with support for Grok and Cursor subscriptions 
(including the new unified X subscription).

## 🚀 Install

Recommended run (no separate install) + auto-updates via the 
[ndx](https://github.com/devlooped/ndx) native dnx runner:

```sh
ndx xsi
```

Alternatively, if you want to install as a dotnet tool (and update manually):

```sh
dotnet tool install -g xsi
xsi
```

The app shares your profile, providers and sessions with CodeAlta.

See [CodeAlta](https://github.com/CodeAlta/CodeAlta) for more information.
